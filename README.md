# CP_NPTEL

Solutions to the NPTEL Competitive Programming course assignments and practice problems.

## Structure

```
CP_NPTEL/
├── Problem_Template/
├── Week_1/
├── Week_2/
├── Week_3/
└── Week_4/
```

Each week's folder contains:

- Assignment solutions
- Practice problems
- Additional problems discussed during the course

## Language

- C++

## Compiler

- g++ (MinGW)
- Visual Studio Code
