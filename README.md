# CP_NPTL

Solutions to the NPTEL Competitive Programming course assignments and practice problems.

## Structure

```
CP_NPTL/
├── Book_English.pdf
├── Problem_Template/
├── Week_1/
├── Week_2/
├── Week_3/
├── Week_4/
├── Week_5/
├── Week_6/                  # Reserved for upcoming work
├── LICENSE
└── comp programming.code-workspace
```

Most problem folders contain:

- `solution.cpp` - C++ solution
- `in.txt` - sample or test input
- `expectedout.txt` - expected output
- `out.txt` - program output for comparison

The repository also includes standalone solution files in some weeks. For example,
Week 2 contains `B_The_Meeting_Place_Cannot_Be_Changed.cpp`, `C_Magic_Ship.cpp`,
and `E_Simple_Skewness.cpp`, while Week 4 contains `C_Destroying_Array.cpp`. These were done with the help of cph helper for codeforces problems, many of the solutions.cpp in these cases do have the links to the cf problems.
